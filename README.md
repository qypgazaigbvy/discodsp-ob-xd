## Overview

discoDSP OB-Xd is an accurate emulation of the Oberheim OB-X synthesizer, meticulously modeling its voice architecture, filter, and the subtle analog imperfections that define its iconic sound.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **discoDSP OB-Xd** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Voice Architecture** | 8-voice polyphony with independent voice detuning and drift |
| **SEM-Style Filter** | 2-pole multimode filter with low-pass, high-pass, and band-pass modes |
| **Unison Mode** | Stack all voices in unison with spread control for massive pads |
| **Free Plugin** | Available as a free download on GitHub and the discoDSP website |
